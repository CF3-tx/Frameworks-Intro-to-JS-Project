# 🇲🇽 Mexico Travel Website (Frameworks & Intro to JS Project)

This project is a front-end replica of the VisitMexico website (https://visitmexico.com/) built with HTML, Bootstrap 5, and JavaScript. For this project, I recreated a simplified version of the website homepage using Bootstrap. After completing the website, I incorporated JavaScript functions to simulate features I would like to improve upon and implement in future projects.

## 🎯 Project Goals

- Recreate a responsive, visually appealing tourism website for Mexico
- Practice Bootstrap layout and component customization (e.g., navbar, forms, tables, cards, carousels, and accordions)
- Enhance interactivity using modern JavaScript features (e.g., form validation, interactive price calculator, feedback storage and interactive buttons)

## 💡 Key Features

- Responsive navigation bar with Bootstrap scroll behavior
- Hero carousel highlighting key destinations
- Bootstrap cards highlighting recommended information
- Bootstrap accordions highlighting suggested trips
- Bootstrap table outlining travel costs for selected destinations 
- Interactive price calculator form, including JavaScript programming (feedback storage, form validation)
- Bootstrap contact form with bootstrap validation
- Footer with an included "back to top" button
